# 垂类定义（MVP）

## 选定垂类

中国短视频创作者，聚焦**大学生活**相关内容。

## 目标用户画像

- 在校大学生或应届毕业生，运营个人创作者账号。
- 常用平台：抖音、小红书。
- 核心目标：发布能提升曝光和涨粉的内容。
- 当前痛点：有选题但难以设计可复用的内容结构。

## 待完成工作（JTBD）

1. 分析爆款脚本，理解其为何有效。
2. 获得带变量占位符的可复用模板。
3. 生成保持结构但更换主题与风格的新脚本。
4. 用统一评分标准快速对比多版草稿。

## MVP 范围

- 输入格式：纯文本脚本。
- 内容长度：80～1200 中文字符。
- 输出语言：简体中文。
- 输出风格控制：平台、受众层级、语气。

## 非 MVP 目标

- 不做完整视频/音频爬取。
- 不做公开趋势抓取。
- 不做多席位协作。
- 不做一键自动发布。

## 成功指标

- 首次分析成功率 > 90%。
- 试点用户 7 日回访率 ≥ 20%。
- 试用用户付费转化率 ≥ 5%。
