# 短视频脚本结构分析 Prompt（基于内容增长知识库）

## 分析框架

参考「爆款拆解卡」与「脚本思维」：叙事结构（开场-冲突-转折-兑现）、传播机制、说服策略、留存与互动触发点。

## 五段结构定义（按语义，非机械分段）

### 1. hook（开场钩子）
- **定义**：前 3 秒 / 第一句抓住注意力的部分。新闻价值：冲突性、接近性、时效性。
- **典型形式**：制造悬念、反常识、情绪点、直击痛点。
- **evidenceSpan**：原文中对应「开场钩子」的 1～3 句，必须是能独立承担钩子功能的原句。

### 2. conflict（冲突引入）
- **定义**：引入痛点、矛盾、张力的部分。让用户产生共鸣：「这事我也遇到过」。
- **典型形式**：常见误区、现实困境、理想与现实的落差。
- **evidenceSpan**：原文中对应「冲突」的句子，与 hook 不同，通常紧随其后展开。

### 3. valueDensity（价值密度）
- **定义**：提供方法、解决方案、可落地价值的核心内容。用户看完能带走什么。
- **典型形式**：步骤、技巧、清单、拆解。
- **evidenceSpan**：原文中对应「价值/方法」的句子。

### 4. evidence（证据佐证）
- **定义**：案例、佐证、社会认同、权威背书。增强可信度。
- **典型形式**：具体案例、数据、他人经历、权威引用。
- **evidenceSpan**：原文中对应「证据」的句子。若无明显佐证，可填空或注明「无」。

### 5. cta（行动号召）⚠️ 关键区分
- **定义**：引导用户做**具体动作**的句子。如：关注、点赞、评论、转发、收藏、点击链接。
- **典型形式**：「关注我」「点赞收藏」「评论区说说你的看法」「转发给需要的朋友」。
- **重要**：若结尾只有**金句/总结**（如「也是一种硬核本事」「不得不说，会找方法懂变通也是一种本事」），这类句子**不是 CTA**，是「金句收尾」。
- **evidenceSpan**：
  - 若有显式 CTA → 填对应原句
  - 若只有金句无 CTA → 填结尾句，**summary 必须写**：「金句收尾，无显式互动引导」
- **禁止**：把纯金句/总结当作 CTA。

## 输出要求

- 按**语义**分段，不是机械按字符数或句数。
- 每段 evidenceSpan 必须不同，覆盖全文。
- 五段顺序：hook → conflict → valueDensity → evidence → cta。
